# Updating this playbook

Keep answers in plain English and make the first response short. Add probes that test reasoning, evidence, failure handling, and communication. Use examples the candidate can defend. Label estimates and unverified claims. Do not add private employer or customer information, credentials, personal contact details, or course recordings/transcripts.

For a new class, copy `templates/session-template.md` into `01-bootcamp-sessions/YYYY-MM-DD-topic/README.md`. Separate what the instructor taught from independent interview preparation. Add a link from the main README.
