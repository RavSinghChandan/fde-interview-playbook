## 🚀 Start in 10 minutes

| Step | Do this | Time |
|:---:|---|:---:|
| 1️⃣ | Read [your positioning](00-start-here/positioning.md) | 2 min |
| 2️⃣ | Say the [90-second introduction](00-start-here/90-second-introduction.md) aloud once. Don't memorise it word for word | 2 min |
| 3️⃣ | Pick one story from the [story bank](03-story-bank/README.md): problem → your action → evidence → trade-off → learning | 4 min |
| 4️⃣ | Keep [the CLEAR answer method](00-start-here/answer-method.md) ready for surprise follow-ups | 2 min |

## 🧭 Study paths

| ⏱️ Time | 📋 What to do |
|---|---|
| **10 minutes** | One short answer + three follow-up questions |
| **30 minutes** | One interview story, then a skeptical follow-up round |
| **60 minutes** | One case: clarify the customer problem → design a thin solution → test failure modes → explain rollout |

## 🌱 How this repository grows

Each class you share becomes a session folder containing:
- what the instructor actually covered
- the concepts in plain English
- interview questions, each with a short answer and an answer under every follow-up
- a practical drill
- links back to your evidence

If a class does not teach a technical topic, the material is labelled as independent interview practice.
